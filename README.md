# DATABRICKS

## Enlaces públicos

- Versión paso a paso (para exponer): https://magalycabrera8.github.io/presentacion-databricks-chec/
- Versión completa (para leer): https://magalycabrera8.github.io/presentacion-databricks-chec/presentacion_completa.html

Navegación: la flecha → avanza, N muestra las notas y F activa la pantalla completa.

Fundamentos de la plataforma Databricks y su aplicación al análisis de criticidad de la red de media tensión de CHEC.

Laboratorio de Inteligencia Artificial – Universidad Nacional de Colombia.

## Cómo verla

1. Descarga uno de los archivos (botón **Download raw file** al abrirlo en GitHub).
2. Ábrelo con doble clic: se abre en el navegador (Chrome, Safari o Edge). No necesita instalar nada.

| Archivo | Para qué |
|---|---|
| `presentacion_por_pasos.html` | Para exponer: cada pantallazo se explica paso a paso con la flecha → |
| `presentacion_completa.html` | Para leer: cada diapositiva aparece completa |

**Teclas:** → avanza · ← retrocede · F pantalla completa · N notas del expositor.
